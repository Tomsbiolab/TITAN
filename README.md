### TITAN - The Integrative Transcript ANnotator

TITAN is an annotation pipeline designed to integrate a custom range and number of gene model evidences from different sources: _ab initio_, transcriptomic, proteomic or annotation liftovers.
This pipeline heavily uses AEGIS functionalities, both core and extended, to perform the following key integration steps: mainly to select the best gene model(s) for each loci, and the corresponding best UTR. In addition, the pipeline is designed to offer a full annotation experience (from input raw data reads and an assembly to a final GFF file), control over external _ab initio_ and other reference transcriptomic evidence software, such as BRAKER and Stringtie, have been incorporated into the initial steps of the suite.
